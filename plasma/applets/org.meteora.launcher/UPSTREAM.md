# Meteora application launcher — KDE Kickoff derivative

This plasmoid derives from the KDE Plasma Desktop Kickoff launcher sources,
tagged at upstream branch `Plasma/6.4` as fetched on 2026-10-15:

https://github.com/KDE/plasma-desktop/tree/Plasma/6.4/applets/kickoff/package

All original SPDX copyright notices and per-file licenses are retained.
Most QML files are **GPL-2.0-or-later**, with some LGPL-2.0-or-later;
upstream authors and license notices remain in each file.

Meteora changes: branded header, launcher icon, grid preference and custom
theme integration. Additional modifications must comply with upstream
GPL/LGPL conditions and retain notices. This directory is **not covered
by the Meteora root MIT license**.
